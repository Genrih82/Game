Доработки ветки feature/task-engine
===================================

Дата: 2026-11-22

Кратко
------
Развитие движка заданий LearnLock: чередование предметов, антиповтор,
ступенчатые подсказки, возрастные рамки по ориентирам Минпросвещения,
автотесты правильности и новый предмет «Английский» (в т.ч. неправильные глаголы).


1. Чередование категорий
------------------------
- Задания идут по кругу: математика → чтение → логика → английский.
- Память последней категории хранится в DataStore (ключ last_task_category).
- Реализация: CategoryRotator + LearnLockRepository / SessionStore.


2. Общий антиповтор
-------------------
- Буфер RepeatAvoidance перенесён на уровень TaskEngine.
- Одинаковые по смыслу формулировки режутся между всеми предметами.


3. Ступенчатые подсказки
------------------------
- У задачи список hints (мягкая → более прямая).
- На экране блокировки кнопка «Подсказка» / «Ещё подсказка».
- LockViewModel хранит hintLevel и currentHint.


4. Новые навыки математики и логики
-----------------------------------
- MATH_DIV (деление без остатка) + шаблоны в math_templates.txt.
- LOGIC_ANALOGY (аналогии вида A → B, как C → ?).


5. Адаптация по «давности» навыка
---------------------------------
- LearnerStats.skillRecency: давно не встречавшиеся навыки получают приоритет
  (AdaptiveSelector, preferStaleChance), не ломая чередование категорий.


6. Соответствие возрасту (Минпросвещение / ФРП НОО)
--------------------------------------------------
- AgeCurriculum: навыки и пределы чисел по возрасту/классу.
  Ориентир: Приказ Минпросвещения № 372, ФРП «Математика» 1–4.
- Примеры:
  - ≤7 лет (1 кл.): без умножения/деления; +/− в пределах ~20;
  - 8 лет (2 кл.): табличные ×/÷ в пределах ~50;
  - английские неправильные глаголы — не раньше ориентира 2 класса.
- Автотесты: AgeAppropriatenessTest.


7. Автотесты правильности заданий
---------------------------------
- TaskCorrectnessTest: контракт Task, один верный вариант в CHOICE,
  арифметика из условия, деление без остатка.
- По ходу тестов исправлены баги: сравнение равных чисел, дубли в «лишнем слове»,
  мало вариантов в последовательностях.


8. Предмет «Английский»
-----------------------
- TaskCategory.ENGLISH, навыки: ENG_VOCAB, ENG_IRREGULAR, ENG_THREE_FORMS.
- Словари: english_vocab.txt, english_irregular.txt.
- Провайдер EnglishTaskProvider.
- В настройках тумблер «Английский».
- Room версия 8: колонки englishEnabled, englishWeight (миграция 7→8).


Затронутые зоны
---------------
- Модуль task-engine (генерация, возраст, английский, тесты).
- Модуль app: репозиторий, сессия, Lock UI подсказок, Settings, AppDatabase.
